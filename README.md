# Smart Expense Tracker

A simple web application to track daily expenses using HTML, CSS, and JavaScript.

## Features

- Add expenses
- Delete expenses
- Calculate total expenses automatically
- Display amounts in Indian Rupees (₹)
- Validate expense inputs

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Example

| Expense | Amount |
|---|---:|
| Food | ₹200 |
| Transport | ₹100 |
| Shopping | ₹500 |
| **Total Expenses** | **₹800** |

The application automatically calculates the total when you add or delete expenses.

## How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/shifashaikh2190/Smart-Expense-Tracker.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.
4. Start tracking your expenses.
